# AutoScroll PDF Reader

AutoScroll PDF Reader is an application designed to make reading digital documents more convenient by automatically scrolling through PDF files at a user-controlled speed. The app allows users to upload or open a PDF and read it hands-free without manually scrolling, making it useful for studying, reviewing documents, or reading while performing other tasks. Users will be able to control the scrolling speed and pause or resume the automatic scrolling as needed. The project will focus on developing a simple, accessible interface while exploring PDF processing, user interface design, and automated scrolling functionality.

Tech Stack: Python, Django
